PORTABILITY NOTES
- i386_decode.c (A): cleanest port target. Pure prefix/opcode/ModR/M/SIB/disp decode
  driven by switch + const REG32_NAMES[8] table; only libc use is snprintf/memcpy/memset
  for byte copy + disassembly string formatting — all expressible in hexa stdlib.
  RUNEQ gate: byte-identical i386_insn_t fields + format string vs C, over a corpus of
  real PE .text entry blocks.
- pe_parse.c (C, with portable kernel): the LE byte readers + PE/COFF/optional-header/
  section-table walk are themselves pure logic (could be Tier-A if fed a buffer), but the
  authored function pe_parse_file() takes a PATH and does open+mmap+munmap. Port path =
  split: hexa-native pe_parse_buf(bytes) (portable) + thin C/FFI file-map ingress (stays C).
  Not split today — classified C as authored.
- pe_to_macho_shim.c (C): MAP_JIT + mprotect + pthread_jit_write_protect_np is the macOS
  hardened-runtime JIT loader contract. No hexa-native substitute — stays C / hexa FFI.
- i386_decode_test.c (B): standalone disassembler tester; retire after Tier-A hexa decode
  reaches RUNEQ parity (its mmap use is test-fixture, not product).
